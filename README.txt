HOW TO UPDATE AN EXISTING GITHUB PAGES SITE:
1. Open the extracted Aaliyah_Portfolio_Resume_Update folder.
2. Go to github.com/aaliyah-nanzee/aaliyah-portfolio.
3. On the Code tab, select Add file > Upload files.
4. Drag ONLY index.html and style.css into the upload area. Their paths should be /index.html and /style.css.
5. Click Commit changes. GitHub will update the existing files.
6. Wait 1–5 minutes for GitHub Pages to redeploy and refresh your public website (Ctrl+Shift+R).

If your repository does not already contain assets/profile-photo.png and assets/sticker-tech-background.png, upload the assets folder too.

To edit locally, open index.html and style.css in VS Code.
